## Milestone 1: Observation store, correlation reader and CLI

- [ ] **system-diagnostics/scripts/observation_store.py**: new, target 220-300 lines. Constants `SCHEMA_VERSION="1.0"`, `ACTIVE_STATUSES=("open","triaged","in_progress")`, `CLOSED_STATUSES=("resolved","dismissed")`, `KINDS=("element","error","network","note")`, `MAX_RECORD_BYTES=65536`, `MAX_MESSAGE=500`, `MAX_TIMELINE=50`, `ROTATE_BYTES=5*1024*1024`, `TRANSITIONS` (parent contract). Functions (each <= 40 lines): `normalize_message(msg)`, `make_fingerprint(kind, page_path, target, message)` -> `OBS-<KIND>-<6HEX>`, `sanitize_record(raw)` (validate kind, drop keys `value`/`password`/`authorization`/`cookie` at any depth, truncate message, cap timeline, reject records over `MAX_RECORD_BYTES` with `ValueError`), `append_raw(workspace, record)` (rotate at `ROTATE_BYTES` to `observations.1.jsonl`, one `open("a")` write of one line), `iter_raw(workspace)` (skips and counts corrupt lines), `load_catalog(workspace)` / `save_catalog(workspace, catalog)` (atomic: write `.tmp` then `os.replace`, same pattern as `trace_recorder.TraceCatalogManager.save_catalog`), `add_observation(workspace, raw)` (sanitize, append, upsert by fingerprint, assign next `OBS-NNN`, reopen a `resolved` entry on recurrence with a history note), `update_status(workspace, id_or_fp, new_status, note="", **meta)` (validates `TRANSITIONS`, raises `ValueError` on illegal), `list_observations(workspace, status="active", limit=20)`, `get_observation(workspace, id_or_fp)`, `summarize(catalog)`. Reuse `defect_catalog.ensure_diagnostics_dir` for the directory and its `.gitignore`; do **not** edit `defect_catalog.py` (346 lines, at the soft budget). Use the same sibling-import pattern as `trace_recorder.register_parser` (try `import x`, fall back to `from . import x`).
- [ ] **system-diagnostics/scripts/observation_correlate.py**: new, <= 200 lines. `parse_iso(ts)` (accept trailing `Z`), `trace_files_for_window(traces_dir, start, end)` (select `trace_YYYYMMDD.jsonl` files whose date falls in the window +/- 1 day), `correlate(obs, traces_dir, skew_s=2.0)` -> sorted list of `TRC-...` fingerprints: exact `context.recording_id` match first; if the observation has no `recording_id`, events whose `timestamp` is inside `[started_at - skew, stopped_at + skew]`. Missing directory returns `[]`. Never raises on a malformed trace line.
